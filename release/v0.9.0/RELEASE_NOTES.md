# README.md v0.9.0

가볍고 100% 오프라인인 마크다운 리더 & 에디터. Windows x64.

테마를 **열어서 고칠 수 있게** 만든 릴리스입니다. 한지·전자잉크가 앱 안에 숨어 있던 값에서 **테마 폴더의 파일**이 되었고, 그 본보기로 **컬러 전자잉크**가 새로 들어갔습니다. 색을 쓰지 않는 전자잉크에서 제목 단계가 눈에 보이게 됐고, **Microsoft Store 로 설치한 경우 테마 폴더가 열리지 않던 결함**을 고쳤습니다.

## 테마가 파일이 되었습니다

**설정(⚙) ▸ [테마 폴더 열기]** 를 누르면 이제 이런 파일들이 들어 있습니다.

```
themes\
├── README.md              무엇을 넣을 수 있는지 적어 둔 안내문
├── 10-hanji.jsonc         한지
├── 20-epaper.jsonc        전자잉크
├── epaper.css             전자잉크의 모양(제목 위계)
├── 30-epaper-color.jsonc  컬러 전자잉크   ← 새 테마
└── epaper-color.css       그 모양과 제목 색 사다리
```

그동안 이 테마들은 앱 안에 값으로 박혀 있어서, 색 하나를 바꾸려 해도 같은 이름으로 **통째로 다시 쓰는** 수밖에 없었고 무엇을 물려받았는지도 보이지 않았습니다. 팩을 주고받자고 만든 기능에서 정작 기본 테마만 못 고치는 것이 앞뒤가 맞지 않았습니다.

- **읽고, 고치고, 지울 수 있습니다.** 지운 테마는 다시 만들어 드리지 않습니다 — 목록에서 그대로 사라집니다.
- 파일 이름 앞의 번호(`10-` `20-` `30-`)는 **읽는 순서**입니다. 같은 이름이 겹치면 뒤가 이깁니다.
- `themes.jsonc` 에서 `"extends": "hanji"` 처럼 **폴더 안의 팩을 바탕으로 삼을 수 있습니다.**
- 라이트·다크·페이퍼 셋은 여전히 앱 안에 있습니다 — 폴더를 통째로 비워도 쓸 수 있는 최소한입니다.

## 컬러 전자잉크 (Color E-Paper)

전자잉크의 무채색 바탕은 그대로 두고 **강조에만** 색이 듭니다.

- 제목은 먹빛에서 감청 · 남색 · 청록으로 내려가고, 마지막 두 단은 회색으로 빠집니다 — 여섯 단이 색으로도 갈립니다.
- 목록 마커와 형광펜은 따뜻한 **황토색**입니다. 제목이 찬색, 표시가 따뜻한색이라 "구조"와 "표시"가 한눈에 갈립니다.
- **렌더 오류만 붉은색**인 규칙은 그대로 남겼습니다.

이 테마는 동시에 **"내 테마 만들기"의 본보기**입니다. 바탕은 그대로 두고 강조 색만 바꾸는, 가장 자주 쓰게 될 방법이 `30-epaper-color.jsonc` 에 주석과 함께 적혀 있습니다.

## 전자잉크에서 제목 단계가 보입니다

색을 쓰지 않는 테마라 그동안 위계를 **크기**만 지고 있었는데, `####` 이하 세 단계는 크기 차이가 거의 없어(1.06 / 1.0 / 0.92배) 사실상 같은 줄로 보였습니다.

이제 모양이 나눠 집니다 — h1은 이중 괘선, h2는 단일 괘선, h3은 왼쪽 굵은 막대, h4는 얇은 막대, h5·h6은 자간을 벌리고 한 단씩 옅어집니다. **색은 한 자리도 직접 적지 않았습니다** — 전부 테마 색에서 계산되므로, 이 파일을 다른 테마에 그대로 베껴 써도 어울립니다.

다른 테마의 제목 모양은 **그대로**입니다.

## 수정

### Microsoft Store 로 설치한 경우 [테마 폴더 열기]가 실패하던 문제
"폴더가 없습니다"라고 하는데, 내보내기 대화상자에서 같은 경로로 들어가면 폴더가 **보이는** 앞뒤가 안 맞는 증상이었습니다.

Windows 는 스토어 앱이 데이터를 쓸 때 **다른 자리로 돌려놓습니다.** 앱은 그 사실을 모른 채 원래 경로를 탐색기에 넘기고 있었고, 탐색기는 그런 폴더를 찾지 못했습니다(대화상자는 앱 안에서 돌기 때문에 보였던 것입니다). 이제 앱이 **실제 자리를 찾아** 넘깁니다.

**파일은 있던 자리에 그대로 있습니다** — 옮기거나 지우지 않습니다. 설정의 테마 파일·폴더 버튼에 마우스를 올리면 실제 경로가 뜹니다.

### 그 밖
- **[테마 파일 열기]가 테마를 만들지 않습니다.** 예시 테마 "내 한지"가 켜진 채로 파일이 만들어져서, 열어 보기만 하려던 분의 테마 목록이 저절로 늘었습니다. 예시는 주석 안으로 들어갔습니다 — 벗기면 그대로 켜집니다.
- **[테마 폴더 열기]가 항상 폴더 *안*을 엽니다.** 폴더에 팩만 있고 안내문이 없을 때 한 단계 위가 열리던 것을 고쳤습니다.

## 알아 둘 점
- 앱 권한 설정(`capabilities`)은 한 글자도 바꾸지 않았습니다. 새 의존성도 없습니다.
- 이미 `themes.jsonc` 를 쓰고 계셨다면 그 파일은 **그대로 둡니다.** 앱이 손으로 쓴 파일을 기계적으로 다시 쓰는 일은 없습니다.
- 한지·전자잉크를 쓰고 계셨다면 업데이트 후에도 그대로 유지됩니다(테마 파일이 자동으로 들어갑니다).
