# README.md v0.6.8

가볍고 100% 오프라인인 마크다운 리더 & 에디터. Windows x64.

**마크다운 작성 기능을 크게 보강한 릴리스.** 단축키 도움말·문단 서식·자동완성·이미지 붙여넣기·표 도구가 들어갔고, 미리보기에서 링크를 누르면 화면이 비던 문제를 고쳤습니다.

## 수정

### 링크를 누르면 미리보기가 빈 화면이 되던 문제
- 문서 안 **`#제목` 링크**와 **다른 문서 링크**를 누르면 미리보기가 하얗게 비던 문제를 고쳤습니다(이전 버전부터 있던 문제).
- 이제 `#제목`은 그 위치로 스크롤하고, 다른 문서는 새 탭으로 열리며, 외부 주소는 브라우저로 열립니다. 앱에서 열 수 없는 파일은 OS 기본 프로그램으로 엽니다.

### 상위 폴더 이미지가 보이지 않던 문제
- `![](../그림.png)`처럼 `..`가 들어간 상대경로 이미지가 표시되지 않던 문제를 고쳤습니다.

## 추가

### 단축키 도움말 (F1)
- 어떤 단축키가 있는지 앱에서 알 방법이 없었습니다. **`F1`** 또는 명령 팔레트(`Ctrl+Shift+P`)의 "단축키"로 전체 목록을 볼 수 있습니다.
- 이미 동작하지만 어디에도 안 적혀 있던 단축키 **27개**도 함께 정리해 실었습니다.
- 명령 팔레트와 편집기 우클릭 메뉴에도 서식 명령과 단축키가 표시됩니다.

### 문단 서식 단축키
- **제목** `Ctrl+1`~`Ctrl+6`(같은 레벨을 다시 누르면 해제) · **인용문** `Ctrl+Shift+Q` · **코드 블록** `Ctrl+Shift+C` · **취소선** `Ctrl+Shift+X`
- **목록** — 글머리 `Ctrl+Shift+8` · 번호 `Ctrl+Shift+7`(선택한 줄마다 1, 2, 3… 자동) · 체크박스 `Ctrl+Shift+9` · 체크 표시 토글 `Ctrl+Shift+Enter`
- **`Tab` / `Shift+Tab` 들여쓰기** · **`Shift+Enter`** 같은 문단 안에서 줄바꿈
- 명령 팔레트에 **번호 다시 매기기**, **수평선 삽입**

### 표 도구
- **`Ctrl+Shift+T`**로 표를 넣고 **`Tab`으로 셀을 옮기며** 파이프가 자동으로 맞춰집니다. 마지막 셀에서 `Tab`을 누르면 행이 늘어납니다.
- **한글은 두 칸으로 계산**해 한글 표도 반듯하게 정렬됩니다.
- 명령 팔레트에서 행·열 추가/삭제와 열 정렬(왼쪽·가운데·오른쪽)을 쓸 수 있습니다.
- 스프레드시트에서 복사한 표를 붙여넣으면 마크다운 표로 바뀝니다.

### 자동완성
- `[링크](` 뒤에서 **워크스페이스 파일 경로**, `](#` 뒤에서 **문서 안 제목**, ` ``` ` 뒤에서 **코드 언어**를 제안합니다. `Ctrl+Space`로 직접 열 수도 있습니다.
- HTML 태그 완성도 함께 동작합니다.

### 클립보드 이미지 붙여넣기
- 캡처한 그림을 편집기에 붙여넣으면 문서 옆 `assets/` 폴더에 저장하고 `![](assets/…)`를 넣어 줍니다. 같은 이름이 있으면 번호를 올려 기존 파일을 덮어쓰지 않습니다.
