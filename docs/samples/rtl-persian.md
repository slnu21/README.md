# اعلامیه جهانی حقوق بشر

> 글 방향(RTL) 회귀 픽스처. `npm run probe:rtl` 이 이 문서를 그대로 열어 미리보기·편집기의 **기하**를
> 잰다 — 페르시아어 문단이 오른쪽 변에서 시작하는가, 인용문 막대·목록 여백이 오른쪽에 붙는가,
> 코드는 여전히 왼쪽인가. 페르시아어 본문은 세계인권선언 1조(UN 공개 번역, unicode.org/udhr)를
> 그대로 베꼈다 — 방향은 글자의 유니코드 속성으로 정해지므로 뜻을 몰라도 판정은 맞는다.
> 이 인용문 자체는 한국어라 문서 안에서 LTR 로 남아야 한다(혼용 회귀).
