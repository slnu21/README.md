# 제품 개요

## 한 줄 정의
**에이전트가 쓴 문서를, 사람이 읽는 자리.** AI 에이전트가 쏟아내는 마크다운을 원하는 워크스페이스로 묶어
읽고·고치고·되돌리는 **경량 데스크톱 리더 & 에디터**. Windows, Microsoft Store 배포, 100% 오프라인.

## 목표
- **경량**: 빠른 실행, 낮은 메모리, 작은 번들 — 숫자는 [performance.md](performance.md).
- **리더 + 에디터**: 실시간 미리보기 분할 뷰, 리딩 모드(좌우 두 문서), 프레젠테이션.
- **워크스페이스**: 폴더 가져오기 + 가상 폴더로 재구성("파일은 그대로, 배치는 내 마음대로").
- **에이전트와 한 짝**: 에이전트가 워크스페이스를 읽게 하고(에이전트 브리지·MCP), 만지고 간 문서를 알아채고
  (받은 문서함), 덮어쓴 것을 되돌린다(문서 기록).
- **풍부한 마크다운**: 표·체크리스트·각주·수식(KaTeX)·다이어그램(mermaid)·코드 하이라이트·콜아웃 등.
- **파일 친화**: 이미지 표시, 파일 연결, 최근, 즐겨찾기, 파일 감시(외부 변경 자동 반영), 새 문서.
- **내보내기**: HTML(자기완결)·PDF·HTML 복사.
- **UX**: 라이트/다크/종이 + 파일 테마(한지·전자잉크 등, 스타일 팩), 한국어/영어, 글 방향(RTL).

## 범위 밖 (현재)
- 실시간 협업·클라우드 동기화(오프라인 우선 원칙).
- 문서를 고치거나 지우는 에이전트 도구(에이전트는 이미 파일시스템으로 할 수 있다 — ADR 0002).
- 모바일(향후 Tauri 모바일 검토).

## 비기능 요건
- 대용량 md 에서도 입력 지연 최소화(에디터 뷰포트 렌더 + 렌더 워커 + 디바운스). 예산: 1MB 문서 타자 p95 50ms.
- Windows 11 기본 지원, Windows 10 검토.
- 네트워크 없이 전 기능 동작(모든 자산 번들, 원격 호출 차단). 에이전트 연결도 같은 기기 안 stdio 뿐이다.
