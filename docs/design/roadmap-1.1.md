# v1.1 진행 계획

- 작성: 2026-10-12 · 기준 판: v1.0.0(GitHub 릴리스 2026-10-12 · Store 는 아직 0.10.0)
- 한 줄: **사람이 읽다가 남긴 표시가 에이전트에게 가는 지시가 된다 — 리뷰 고리의 반대쪽 절반.**

## 0. 순서를 바꾼 이유 (사용자 결정 2026-10-12)

1.0 계획([roadmap-1.0.md](roadmap-1.0.md) 7절)은 "촬영 → Store 1.0 제출 → 1.1"이었다. 사용자 결정으로 **후속 기능을
먼저** 한다.

- **1.0.0 은 릴리스 파일만 준비된 상태로 둔다** — GitHub 릴리스 v1.0.0 · `release/v1.0.0/` 산출물. Store 에는 따로
  내지 않는다.
- **1.1 기능을 끝낸 판으로 한 번에 촬영하고 Store 에 낸다** — 0.10.0 → 1.1.0 으로 Store 가 한 번에 건너뛴다. 1.0 의
  고친 것(브리지 다섯 · 색인 누락 · 위치 버그 둘 · 성능)은 그 판에 함께 실린다. 스크린샷 8장 계획([shoot-v100.md](../video/shoot-v100.md))은
  펜 화면을 넣어 그때 다시 고른다.
- **지금 하는 브리지 실사용(U2, ~10-18)에서 나온 변경은 Store 제출 뒤 다음 마이너로** 낸다. 실사용은 계속하고
  기록만 [notes/bridge-dogfood.md](../notes/bridge-dogfood.md) 에 쌓는다. 단, **이미 1.1 후보로 옮겨 둔 브리지 소품 둘**
  (검색 결과 줄 번호 · 0건 힌트)은 1.1 에 곁들인다(같은 날 결정).

## 1. 1.1 이 무엇인가

- **표시 펜** — [ADR 0003](decisions/0003-annotation-pens.md). 리딩 화면에서 형광펜·밑줄·물결·취소선·동그라미 · 점 표시 넷
  · 여백 세로줄 · 메모. 위치는 좌표가 아니라 **스냅샷 원문의 글자 범위**라 리플로우·문서 변경에도 따라가고, 에이전트가
  고친 자리는 **바뀜**으로 드러난다. 에이전트는 `list_annotations` 로 표시와 그 **뜻**을 읽는다.
- **브리지 소품** — 실사용에서 나온 것 중 작고 바로 쓸모 있는 둘.
- **유료화(T7)는 정하지 않고 둔다** — 펜이 동작한 뒤(V3 끝) 판단한다. 게이팅 코드는 미리 넣지 않는다.

## 2. 작업 단위 (순서대로)

각 단위는 `develop-<slug>` 하나 = 데브로그 하나.

### V1 · `annot-anchor` — 앵커 코어 (순수 로직, 2~3 세션) — ✅ 10-12 (06)

ADR 의 "가장 어려운 곳"을 먼저 닫는다. 전부 순수 함수 + vitest — 화면·저장 없이 끝난다.

- **diff** — 줄 단위 Myers + 바뀐 줄 안 글자 단위(직접 짠다 · 새 의존성 0). 입력은 스냅샷 원문 · 지금 원문(LF 정규화).
- **범위 옮기기** — `(src_start, src_end)` 를 옛 판 → 지금 판으로. 상태 넷: 그대로 · 옮겨짐 · **바뀜**(범위 안 글자가
  수정 — 지금 판의 대응 범위 + 이전/지금 문자열) · 사라짐(범위 전체 삭제).
- **TextQuote** — `quote`/`prefix`/`suffix` 를 만들고, 주어진 블록 텍스트 안에서 찾는다(여럿이면 문맥 점수 · 소스
  위치에 가까운 것).
- **렌더 ↔ 소스** — 블록의 렌더 텍스트와 소스 줄 사이 대응(`**`·링크 문법·이스케이프·인라인 코드를 건너뛰는 글자
  지도). 선택 → 소스 범위, 소스 범위 → 렌더 텍스트 오프셋. mermaid·수식·코드 블록 안쪽은 "범위 펜 불가"로 판정.
- 완료: `lib/annot/*.ts` + 테스트(에이전트식 수정 픽스처 — 문단 끼우기·문장 고치기·절 삭제·표 행 추가·CRLF·한글·RTL).

### B1 · `bridge-search-lines` — 검색 결과에 줄 번호 + 0건 힌트 (1 세션) — ✅ 10-12 (07)

- `search_docs` 결과 항목에 **맞은 첫 줄 번호** — 바로 `read_section(line)` 으로 갈 수 있게. 스니펫 위치에서 계산.
- 0건이면 "스코프 안 문서 N개 · 범위(`root`)를 넓히거나 다른 낱말로" 한 줄(ko/en).
- 출력 모양이 바뀌므로 agent-bridge.md 계약 갱신 · 릴리스 exe MCP 실구동.

### V2 · `annot-store` — 저장 (1~2 세션) — **마이그레이션 v5 = 확인 게이트** — ✅ 10-12 (08, 자율 진행 지시를 승인으로)

- `annotation` 표(ADR 스키마) · CRUD 커맨드 · 펜 뜻은 `settings`.
- 스냅샷 기록 고칠 곳 넷: 다는 순간 지금 판을 뜸 · 합치기 창 무시 · **참조된 판은 정리에서 제외** · 색인 대상 밖도 뜸.
- `cargo test`(정리 예외가 바탕 판을 지키는지 · v4 → v5 판올림 · 실사용 DB 사본 리허설).

### V3 · `annot-ui` — 화면 (3~4 세션) — ✅ 10-12 (09) · 유료화 판단은 대기

- iframe 안 SVG 층 둘(글자 밑/위) · `getClientRects` 재계산 · 질감 필터 · 펜 트레이(선택 시) · 여백 ＋ · 메모 접힘/툴팁/
  레일(폭을 재서) · `--mark-*` 토큰 10개 + 대비 테스트 · 저장 안 한 편집이면 막기 · ko/en.
- **`probe:annot` 신설** — 폭·테마·RTL·분할에서 표시가 글자를 따라가는지 기하로 잰다. 질감 켜고 끈 재그리기 ms 를
  `perf-budget.json` 에 넣어 "끄는 기준"을 숫자로.
- 실구동(임시 식별자 빌드 — 실사용 데이터 무접촉).
- 끝에 **유료화 판단**(사용자 결정).

### V4 · `annot-share` — 내보내기 · 브리지 · 요약 복사 (1~2 세션) — ✅ 10-12 (10) · PDF 는 CSS 표시(ADR 에서 바꿈)

- 내보내기 [표시 포함]·[메모 포함](기본 꺼짐) — PDF 는 SVG 굽기, HTML 은 CSS 표시, 메모는 끝 절.
- MCP `list_annotations(path)` — `meaning`·`state`·`line` · 스코프는 `scope.rs` 공유 · 금지 이름 테스트 유지.
- [리뷰 요약 복사] — 칠한 문장 + 뜻 + 메모를 마크다운 목록으로.

### R · `release-v110` — 1.1.0 출하 (2 세션) — 배포 준비 ✅ 10-13 (04) · 촬영이 결함 다섯을 찾아 고침 · 영상은 이번 제출에서 안 바꿈 · push·태그·릴리스·Store 제출 대기(확인 게이트)

- 버전 1.0.0 → 1.1.0 · CHANGELOG/릴노트(1.0 의 고친 것도 Store 사용자에겐 처음이라 What's new 에 함께) · NOTICES diff.
- **촬영** — 스크린샷 8장 재선정(펜 한 장 이상) · 영상 비트 · 임시 식별자 `com.readme.shoot`.
- push · 태그 · GitHub 릴리스 · **Store 제출(사용자 직접 · 리스팅·스크린샷·영상·MSIX 한 제출)** — 확인 게이트.

## 2.5 같은 날 바뀐 것 (사용자 결정 2026-10-12 밤)

- **표시 펜은 무료**로 둔다 — 유료화(T7)는 펜이 아니다.
- **캔버스(ADR 0004)를 1.1 에 넣는다** — "다음 작업도 자율로, 그 버전 기준으로 스토어 배포 준비까지". 1.1.0 도 1.2.0 도 아무 데도
  안 나갔으므로 번호를 건너뛰지 않고 **1.1.0 = 표시 펜 + 캔버스**(0.10.0 에 RTL 을 태운 것과 같은 이유).
- 캔버스 단위: C1 `canvas-format`(형식·기하·경로) → C2 `canvas-view`(화면 · 카드 두 단계 · `probe:canvas`) → C3 `canvas-integration`
  (검색·받은 문서함·기록·트리·새 캔버스) → C4 `canvas-ink`(드로잉 + **옵시디언 왕복 실측**). `.canvas` 파일 연결(MSIX)은 확인 게이트라 뺀다.
- 그다음 R = 1.1.0 배포 준비(버전 · 빌드 · 패키지 · 리스팅 · 스크린샷). push·태그·릴리스·Store 제출은 확인 게이트.
