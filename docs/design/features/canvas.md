# 캔버스 (문서 지도)

결정과 근거는 [ADR 0004](../decisions/0004-canvas-document-map.md), 동작 시안은 [mockups/canvas.html](../../mockups/canvas.html).
여기는 **구현이 실제로 어떻게 생겼는지**와 지켜야 할 불변식이다.

## 한 줄

디스크의 `.canvas`(JSON Canvas 1.0 — 옵시디언과 같은 형식)를 탭으로 열면 편집기·미리보기 대신 캔버스가 뜬다. 탭 내용이 곧 JSON 이라
**저장·자동저장·되돌리기·밖에서 고침 감지가 다른 문서와 똑같이 돈다.** file 카드는 읽으러 가는 길이다 — 더블클릭 = 그 문서 탭.

## 자리

| 무엇 | 파일 |
|---|---|
| 형식(읽기·쓰기·보존) | `app/lib/canvas/format.ts` |
| 기하(연결점·곡선·달라붙기·변 고정·확대) | `app/lib/canvas/geometry.ts` |
| file 노드 경로(볼트 기준) | `app/lib/canvas/paths.ts` |
| 카드 정보(제목·아웃라인·첫 문단) | `app/lib/canvas/cards.ts` ↔ Rust `commands/canvas.rs` |
| 화면 | `shell/CanvasView.tsx` · `shell/canvas.css` |
| 프로브 | `npm run probe:canvas`(`tools/canvas-probe.mjs` · `app/dev/canvasProbe.ts` · 픽스처 `docs/samples/map.canvas`) |

## 지킬 것

- **파싱한 객체를 그대로 들고 고친다** — 노드·선·최상위의 모르는 필드(옵시디언 `styleAttributes`·`metadata` 등)가 저절로 보존된다. 형식이 틀린
  노드·매달린 선도 지우지 않고 그리지만 않는다. JSON 이 아니면 **열지 않고 저장도 안 한다**(빈 캔버스로 덮으면 원본이 날아간다).
- **file 경로는 볼트 루트 기준**(옵시디언). 읽기 후보 = 볼트(`.obsidian` 조상, Rust) → 캔버스 폴더 → 조상. 쓰기 = 볼트 안이면 볼트 기준,
  밖이면 캔버스 폴더 기준. 후보 규칙은 프런트에만 있고 Rust 는 "처음으로 있는 것"만 고른다(규칙이 한 벌).
- **카드 내용은 색인에서**(없으면 디스크, 1MB 까지) · 헤딩은 브리지 `outline` 과 같은 Rust 파서. 본문 렌더(수식·다이어그램)는 안 한다.
- **층마다 z-index**(그룹 0 → 선 1 → 카드 2 → 라벨 3 → 선 끝 손잡이 4) — 층이 쌓임 맥락이어야 카드 연결점(z-index 2)이 카드 층 밖으로 못 나온다.
  처음엔 안 줘서 **연결점이 선 끝 손잡이를 덮었고, 손잡이를 잡으면 새 선이 생겼다**(probe:canvas 가 잡음 — ADR 5절의 시안 사고 그대로).
- **world 안에는 flex 를 쓰지 않는다** — scale 된 world 안 flex+overflow 는 크롬이 통째로 안 그린다(시안 실측). 프로브가 **스크린샷 픽셀**로 카드 자리가
  카드 배경색인지 본다(카드를 숨기면 FAIL 하는 것을 확인 — 처음 판은 그룹 색·점무늬 때문에 숨겨도 통과했다).
- 선 끝을 옮기면 **반대쪽 변을 고정 저장**(변 없는 선의 자동 계산이 출발지를 바꾸지 않게).
- text 노드는 **남이 쓴 마크다운** — `html:false` markdown-it + DOMPurify, 앱 DOM 에 그린다.
- 처음 열 때 **전부 보이게** 맞춘다(기억한 시점이 있으면 그것). 기억 여부는 마운트 때 잰다 — 시점을 기억하는 이펙트가 먼저 돌아서
  처음에도 "기억함"으로 보였다(픽셀 검사에서 카드가 화면 밖이라 찾음).

## 다른 기능과 (C3)

| 기능 | 캔버스에서 |
|---|---|
| 검색 | `.canvas` 를 색인하되 **사람이 쓴 글만**(text 노드 · 그룹·선 라벨 · file 경로 · link 주소, `search.rs canvas_text`). JSON 키·숫자는 안 들어간다 |
| 문서 기록 | **색인할 때마다 지금 원문(JSON)을 뜬다** — 색인 내용이 뽑아낸 글이라 "덮기 직전 색인 내용"으로 뜨면 되돌릴 때 JSON 이 망가진다. 지울 때도 색인 내용으로는 안 뜬다 |
| 받은 문서함 | 다른 문서와 같다(색인 메타) — 에이전트가 고친 지도가 아침에 뜬다 |
| 워크스페이스 트리 | `.canvas` 가 열 수 있는 문서로 보이고, **트리에서 끌어 캔버스에 놓으면 file 노드**(참조 — 이동이 아니라 가져온 폴더 안 파일도 된다) |
| 새로 만들기 | 팔레트 [새 캔버스] — 빈 파일 = 빈 캔버스 |
| 브리지 | `open_in_app`·`place_doc` 이 `.canvas` 를 받는다(에이전트가 남긴 지도를 사람 화면에) · `search_docs` 는 캔버스 결과에 `line` 을 안 준다(색인 내용의 줄이라 파일과 안 맞는다) |

**감시기의 색인 대상 판정은 `search.rs` 하나만 쓴다** — `watch.rs` 에 사본이 있었고, `.canvas` 를 색인에 넣을 때 그쪽만 빠져 밖에서 고친 캔버스가
다시 색인되지 않았다(실구동에서 찾음).

## 드로잉 (C4)

- 도구 [선택]·[펜]·[지우개] — 펜은 **색연필·형광펜 + 색 다섯(표시 펜과 같은 `--mark-*`)** · Esc = 선택으로. 펜 모드에선 연결점을 숨긴다.
- 저장 = 최상위 **`x-readme-ink`**(`lib/canvas/ink.ts`) · 좌표 소수 한 자리 · 필드 안 모르는 키와 틀린 획은 그대로 둔다 · 다 지우면 필드를 뺀다.
- 그리기 = world 안 SVG 층(라벨 위 · 선 끝 손잡이 아래, z-index 4) · 형광펜은 곱하기(다크는 스크린) · **질감 필터는 획마다 자기 상자**(표시 펜과 같은
  이유 — 층 전체에 걸면 다시 칠하기가 캔버스 크기를 따른다) · 설정의 [표시 질감]을 같이 따른다.
- 지우개 = 획의 **선분** 근처(점만 보면 긴 직선 가운데를 못 지운다) · 형광펜은 두꺼운 만큼 더 넓게.
- 옵시디언 보존: 설치본 앱 번들의 직렬화를 읽어 확인(ADR 0004 6절) — 실제 왕복은 사용자 볼트를 건드릴 위험 때문에 안 했다.
