# 2026-10-11 (08) [v1.0 U6] 브리지가 떠 있는 채로 업데이트 — 실측 + 곁다리 결함(재색인 중 검색 누락)

브랜치 `develop-update-measure` · (07)에서 세운 확인 항목 ①~④를 쟀다.

## 어떻게 쟀나 — 실사용 데이터에 안 닿게

- **식별자를 바꿔 두 판을 빌드** — 0.10.0 태그(스키마 v3)와 main(v4)을 detached worktree 에 꺼내 `identifier`·
  `APP_IDENTIFIER` 만 `com.readme.updtest` 로(커밋 안 함). 데이터가 `%APPDATA%\com.readme.updtest` 나 임시 패키지
  컨테이너로만 간다 → `userdata.ps1` 이 필요 없다. 이 세션 자신의 브리지(Store 0.10.0)가 실사용 DB 를 잡고 있어서
  폴더 비켜 놓기는 어차피 거부됐을 것이다.
  - 식별자를 안 바꾸고 패키지만 임시로 하면 위험했다 — 쓰기 가상화는 이미 있는 폴더를 그대로 통과시키므로
    (app_paths.rs) 임시 패키지가 **실사용 DB 를 판올림**한다.
- **임시 신원 MSIX** `SlnU.README.md.UpdTest` · 별칭 `readme-md-updtest.exe` · 기존 신뢰 인증서로 서명(관리자 불필요).
  실명이 새면 패킹 스크립트가 멈춘다. 끝나고 패키지·데이터 제거, Store 설치본 `0.10.0.0` 그대로 확인.
- 장치를 저장소에 남겼다: `packaging/update-check/`(pack-temp.ps1 · update-run.mjs · coexist.mjs · README).
  스키마가 바뀌는 릴리스마다 다시 돌린다.

## 숫자가 이상해서 판 것 둘

1. **첫 공존 실측이 "전부 통과"였는데 새 앱이 3ms 만에 종료 코드 0 으로 끝났고 DB 가 v3 그대로였다.** 옛 앱이 살아 있어
   새 앱이 single-instance 로 넘겨진 것 — 이어지는 검사는 옛 앱 페이지를 상대로 통과했다. 원인 둘: `taskkill`(강제 아님)
   으로는 앱이 안 닫힌다 · 강제 종료 필터의 `'D:\build…'` 에서 JS 가 `\b` 를 백스페이스로 먹어 아무것도 안 잡았다.
   → 닫기는 `/T /F` + 소멸 확인, 경로는 환경변수로, 새 앱이 측정 내내 살아 있지 않으면 무효로 멈춘다.
2. **재색인을 겹치면 옛 브리지 검색 13,943회 중 899회가 30건을 못 채웠다.** 처음엔 파일을 안 바꾸고 재색인해서(=쓰기 0)
   통과했던 자리다 — 매 회 30개를 고치게 바꾸자 나왔다. 옛 브리지 탓이 아니다: `index_file` 이 기록 뜨기·옛 행 지우기·
   새 행·메타를 **트랜잭션 없이** 따로 커밋했고(폴더 색인은 바깥 묶음이 감싸지만 **감시기·단일 재색인은 안 감쌈**),
   지우기와 넣기 사이에 읽으면 그 문서가 없다. 앱 자신의 검색도 같다. 도중 실패면 행이 지워진 채 남는다.

## 고친 것

- `commands/search.rs` — `index_file`·`remove_path` 를 `in_savepoint` 로 감쌌다. 바깥 트랜잭션 안에서는 그 일부, 밖에서는
  그 자체로 한 트랜잭션. 덤으로 감시기 경로의 커밋(WAL fsync)이 파일당 서넛 → 하나. 재실측 **899 → 0**(13,670 · 14,514회).
- 테스트 둘: 메타 갱신을 트리거로 실패시켜 옛 행이 그대로 찾아지는지(**SAVEPOINT 를 잠시 끄고 FAIL 을 먼저 봤다** —
  "옛 내용은 그대로 찾아져야 한다") · 바깥 트랜잭션을 되돌리면 안쪽도 사라지는지.
- README 연결 절(ko/en)에 업데이트 한 줄 — 연결 중엔 Windows 가 앱이 실행 중이라고 본다 · 닫았다 다시 열기 · 끊기면 `/mcp`.
- 문서: features/agent-bridge.md "업데이트" 절 · data-model.md(한 덩어리 규칙 · 판올림 호환 규칙) · notes/development.md
  (single-instance 거짓 통과) · roadmap U6 결과 · CHANGELOG Unreleased(Fixed 한 줄).

## 남은 것

- **Store 가 실제로 어느 방식인지는 못 봤다**(임시 신원은 Store 를 안 거친다) — 1.0 게시 뒤 브리지를 붙인 채 Store 업데이트를
  받아 `Get-AppxPackage` 판과 브리지 생사를 본다. 사용자에게 할 말은 어느 쪽이든 README 의 그 한 줄이다.
