# 2026-11-15 (02) 웹 에디션 W1 — 같은 저장소의 웹 빌드 타깃(`@platform` 인터페이스 + 구현 둘)

브랜치 `develop-web-edition` · [TASKS](../TASKS.md) · 설계 승인 2026-11-15(포지셔닝·매핑·사이드바) · **머지 전(사용자 검토 대기)**

## 배경

웹 = 파일 하나를 브라우저에서 열고·읽고·고치는 무료판(업로드 없음), 데스크톱 = 워크스페이스·검색·기록·받은 문서함·에이전트 브리지.
포크하지 않고 같은 저장소에서 빌드만 갈라 데스크톱 빌드·동작은 그대로 둔다.

## 변경

- **플랫폼 경계** — `app/lib/tauri.ts` → `app/platform/tauri.ts`(git mv). 앱 코드는 전부 `@platform` 으로 import(17곳).
  `vite.config.ts` alias: 기본·vitest·프로브 = `platform/tauri.ts`, `--mode web` = `platform/web/index.ts`. tsc 는 `tsconfig paths` 로 데스크톱 타입을 보고,
  **`platform/conformance.ts`** 가 `typeof Desktop = Web` 대입으로 웹 구현이 같은 이름·같은 모양인지 컴파일 시간에 잰다(번들에는 안 들어감).
  표시 펜(`lib/annot/api.ts`)·캔버스(`lib/canvas/cards.ts`)의 `invoke` 도 `platform/tauri.ts` 로 옮겨 **Tauri API 직접 호출은 한 파일**.
  공용 타입은 `platform/types.ts`, 판 표 `features`(workspace·search·history·inbox·agentBridge·annotations·canvas·userThemes·windowControls·revealInExplorer).
- **웹 구현**(`app/platform/web/`):
  - `files.ts` — 가상 경로 `/web/<id>/<이름>` 등록부(앱의 탭·최근·세션 복원이 경로를 식별자로 쓰므로). 핸들 있으면 읽기·제자리 쓰기(권한은 쓸 때),
    없으면 메모리 + 저장 시 저장 위치 고르기(지원 시) 또는 다운로드. 같은 파일 재열기는 `isSameEntry` 로 같은 경로.
  - `pick.ts` — `showOpenFilePicker`/`showSaveFilePicker`, 폴백 `<input type=file>` + 다운로드. `drop.ts` — 앱 문서 + **미리보기 iframe** 양쪽 드롭(capture, 파일 드래그면 전파 끊음 — CodeMirror 가 파일을 글로 끼우거나 브라우저가 파일로 이동하지 않게).
  - `settings.ts` localStorage(던지면 메모리) · `recent.ts` IndexedDB(핸들 그대로, 핸들 없는 문서는 1MB 까지 내용 사본) · 테마는 기본 팩을 번들 원문으로(`readThemeBundle`).
  - 데스크톱 전용 호출은 `EWEB` 로 거절(조용히 성공하지 않게) · 감시·색인·받은 문서함은 빈 결과로 조용히(부팅 경로 보호).
- **웹 사이드바** `shell/WebSidebar.tsx` — 목차(미리보기 TOC·오버레이와 같은 이동) · 최근 파일 + 사용법 3줄 · **300×250 안내 자리**(`contain:strict` 로 크기 예약, 광고 코드 없음 — 데스크톱 앱 소개·단축키) · Store 링크.
  타이틀바 접기 버튼(접으면 자리째 사라짐 · `sidebarCollapsed` 영속) · ≤900px 에서 숨김. 클래스 `wsb-*`(mermaid 클래스와 안 겹치게).
- **UI 분기**(features 상수): 웹에서 검색창·받은 문서함·창 버튼 숨김 · [폴더 열기]는 "데스크톱 앱에서" 안내 + Store · 팔레트/탭 메뉴/내보내기 메뉴에서 기록·표시 펜·캔버스·워크스페이스 항목 제외 ·

## 결정·함정

- 새 문서는 데스크톱처럼 "경로 먼저" — 웹도 저장 위치를 먼저 고른다(지원 브라우저). 폴백은 이름만 정한 가상 문서이고 **만들 때는 다운로드하지 않는다**(저장할 때만).
- 핸들 없는 문서에 자동저장을 켜면 저장마다 파일이 떨어진다 → `canAutosave` 를 플랫폼 함수로.
- 미리보기 iframe 에 드롭 리스너가 없으면 브라우저가 떨어진 파일로 **탭을 이동**한다(편집 손실) — `attachFrameDrop` 를 iframe load 마다.
- PowerShell 5.1 `Set-Content -Encoding utf8` 은 BOM 을 붙인다(테스트 파일 한 번 — 바로 걷어냄). 로케일 JSON 은 CRLF 작업본이라 끼워 넣을 때 고립 CR 을 만들었다(git 이 `-text` 로 봄) — 고침.
