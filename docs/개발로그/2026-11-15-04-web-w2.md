# 2026-11-15 (04) 웹 에디션 W2 — 배포 설정·랜딩·언어 URL·URL 로 열기·공유 링크·PWA

브랜치 `develop-web-w2` · [TASKS](../TASKS.md) · 주소 `https://md.ondolworks.com`(Cloudflare Pages · 브랜드 Ondol Works) · **머지 전(사용자 검토 대기)** · 배포·Cloudflare 작업 안 함

## 배경

W1(웹 빌드 타깃)은 main 에 들어갔다. W2 는 실제로 내보낼 수 있는 사이트로 만든다 — 정적 랜딩·언어별 URL·검색엔진 파일·보안 헤더·오프라인.
진행 중 사용자 설계 변경: **"첫 화면은 기능만, 스크롤을 내리면 설명이 쭉"** — 숨긴 도움말 대신 앱 아래 보이는 본문.
절대 원칙은 그대로: 데스크톱 산출물은 main 과 바이트 동일.

## 변경

- **정적 사이트 생성**(`app/platform/web/site/` — `routes.ts` 경로 표 · `copy.ts` 문구 ko/en · `pages.ts` 생성기, 순수 문자열 함수)을

    `<html lang data-route data-mode>`, self-canonical + hreflang(en·ko·x-default=en), og, JSON-LD(데이터 블록), 언어별 manifest.
  - 루트 `/` = 언어 고르기(`lang-redirect.js` — 마지막 언어 선호 → 브라우저 언어, `?url=`·`#` 그대로 넘김 · 스크립트 없으면 링크). 같은 브랜드 timer.ondolworks.com 과 같은 규칙.
  - `404.html`(noindex) · `_headers` · `_redirects`(`/mermaid-preview` 등 언어 없는 주소 → en, 301) · `sitemap.xml`(8 URL, 각자 hreflang) · `robots.txt` · `sw.js` · 아이콘(src-tauri/icons 복사 + SVG).

- **첫 화면 = 앱, 아래 = 설명 본문**: `#root` 뒤에 보이는 정적 DOM(이 랜딩 소개 · 사용법 · 지원 문법 · 링크로 열기/공유 · 오프라인·개인정보 · 데스크톱 앱 · 다른 도구 · 언어 · 푸터 Ondol Works).
  앱은 `100svh`·`width:100%`, 상태바 가운데에 조용한 "아래에 설명 ↓" 힌트.
- **스크롤 충돌 해법**(앱 안 = 내부 스크롤, 앱 크롬·힌트 = 페이지 스크롤):
  - 편집기·사이드바 `overscroll-behavior: contain`, 미리보기 iframe 은 실을 때마다 `html,body{overscroll-behavior:contain}` 주입(`attachFrameDrop` — 웹 전용 훅) — 끝에 닿은 휠이 페이지로 사슬을 넘기지 않는다.
  - **프로그램 스크롤도 새면 안 된다**(프로브가 잡음): 목차 클릭 → iframe `scrollIntoView` 가 바깥 페이지까지 708px 굴렸다 → iframe 의 `Element.prototype.scrollIntoView` 를 iframe 안에서만 계산(`frameScrollTop`).
    그다음 편집기 동기 스크롤이 CodeMirror `scrollRectIntoView` 로 `window.scrollBy` 82→171px — CM 은 sticky/fixed 조상에서 걷기를 멈추므로 `.cm-editor{position:sticky !important}`(CM 기본 테마가 `relative !important`, 오프셋 없는 sticky = relative 배치).
  - 접기 버튼 `fixed` → `absolute`(스크롤하면 앱과 함께 올라감).
- **언어 = URL**: 스토어가 만들어지기 전에(platform/web 모듈이 store 보다 먼저 평가된다) 영속 상태의 `language`·`readerMode` 를 페이지 것으로 패치(`page.ts`) — 첫 페인트부터 그 언어·그 보기.
  앱에서 언어를 바꾸면 **다른 언어 URL 로 이동**: 열린 탭 전부(내용·미저장·파일 핸들)를 IndexedDB 에 보관(`stash.ts`, 5분·1회) → 이동(beforeunload 생략) →
  새 페이지의 세션 복원이 보관본을 읽고, 훅이 빠진 탭을 마저 열고 활성 탭·미저장 표시를 되돌린다. 보관 실패 + 미저장이 있으면 이동하지 않고 안내.
- **URL 로 열기**(`remote.ts`): `?url=` + 팔레트·빈 화면 [URL로 열기…]. github blob/raw/tree/저장소 → raw.githubusercontent · gist → raw · gitlab `-/blob/` → `-/raw/` · https 만(http 는 루프백만).
  가상 경로 `/web/url/<host>/<경로>` — URL 이 경로에 들어 있어 상대 이미지·링크가 평소 경로 해석만으로 같은 저장소 주소가 된다(`readFileBase64`·`readFile` 이 받아 옴).
  실패는 이유별 안내(CORS/네트워크 · HTTP 코드 · 5MB 초과 · HTML 페이지 · 시간 초과). 앱 안에서 열면 주소창에 `?url=` 을 `replaceState`(새로고침 없음).
- **공유 링크**(`share.ts`·`bytes.ts` — static-kit(MIT, 같은 저작자)의 base64url·deflate-raw 를 옮김, 새 의존성 0): `#n=<이름>&md=<base64url(deflate-raw)>` ·
  상한 32,000자(초과 시 길이·상한 안내) · 열면 해시를 걷음 · 같은 링크 = 같은 경로 · 이미 열린 탭에서 해시만 바꿔도 `hashchange` 로 연다 · 깨진 링크 안내.

## CSP 결정

`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https:; font-src 'self' data:; connect-src 'self' https:; worker-src 'self' blob:; frame-src 'self'; manifest-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'`
- 데스크톱 하드닝 CSP 를 옮기고 두 곳만 연다. **img-src https:** — README 의 배지·스크린샷 출처가 제각각(shields.io·CI·user-images…)이라 허용 목록이면 README 미리보기가 깨진다. 이미지는 수동 콘텐츠, 미리보기는 스크립트 없는 샌드박스 iframe + DOMPurify. `http:` 는 열지 않음.
  **connect-src https:** — `?url=` 원본이 사용자가 고른 임의 HTTPS(CORS 허용). 스크립트는 `'self'` 뿐이라 이 통로로 코드를 들일 수 없다.
- 인라인 스크립트 0(루트 이동도 파일) · JSON-LD 는 실행되지 않는 데이터 블록. `frame-ancestors 'none'`(클릭재킹). 광고를 붙일 때 그 도메인만 더한다.
- `_headers` 캐시: `/assets/*` 1년 immutable · HTML·`sw.js`·manifest no-cache. **`/*` 에 Cache-Control 을 두지 않는다** — Pages 는 겹치는 규칙의 같은 헤더를 쉼표로 합친다(테스트가 지킨다).

## 결정·함정

- **프로브가 잡은 것**: 헤드리스 Edge 가 시스템 로캘(ko)이라 루트가 /ko/ 로 갔다(정상 동작) → `--lang=en-US` 로 고정. 클립보드 쓰기가 포커스된 창에서 끝나지 않아 공유 대화상자가 안 떴다 → 1.5초 경쟁.
  목차·동기 스크롤의 바깥 페이지 스크롤(위 해법). 폰 폭 430px 넘침 둘(툴바 최소폭 · 본문 긴 URL).
- 언어 전환을 앱 안 전환(replaceState)으로 하지 않은 이유: 주소창 언어 = 화면 언어 = 정적 본문·hreflang 이어야 한다. 이동 1회 + 보관 복원이 편집 손실 없이 맞춘다. 개발 서버(`dev:web`)는 언어별 페이지가 없어 앱 안 전환만.
- 세션 복원(`openPaths`)은 같은 브라우저의 다른 탭이 덮어쓸 수 있다 → 보관본의 탭 목록으로 빠진 탭을 마저 연다.
- 웹 훅이 `platform/web/index.ts`(부작용 있음)를 import 하면 데스크톱 번들에 웹 코드가 남는다 → 부작용 없는 `bridge.ts` 에 자리를 두고 index 가 구현을 꽂는다(최상위 `new Map()` 도 지연 생성).
- PowerShell 로 CRLF 파일을 LF 문자열로 치환하면 조용히 안 바뀐다(몇 번 놓침) — 바꾼 뒤 grep 으로 확인.
