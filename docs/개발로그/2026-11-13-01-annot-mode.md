# 2026-11-13 (01) 표시 펜 사용 모드(켜기·보기만·끄기) + 메모 레일이 "좁다"며 안 펼쳐지던 것

브랜치 `develop-annot-toggle` · [features/annotations.md](../design/features/annotations.md) · 1.1.0 실사용 피드백 2건

## 신고

1. 글을 드래그할 때마다 펜 트레이가 떠서 오히려 거슬린다 — 설정에서 메모 사용 여부를 고를 수 있으면 좋겠다.
2. 리딩 모드에서 화면이 넓은데도 메모를 펼치면 "창이 좁아 메모를 툴팁으로 보여 줍니다"가 나온다.

## 원인 (2)

레일 판정이 **카드를 그대로 두고** 남는 폭에 레일(300 + 20)이 들어가는지만 봤다.

- 리딩 폭 **[넓게]** 는 `.md` 에 `max-width` 가 없어 카드가 늘 창 전체다 → **어떤 창에서도** 안 들어간다.
- **[보통]**(860)도 카드 + 레일 + 여백 = 약 1,210px 를 요구한다 — 배율 150% 화면(1920 → 1280 CSS px)에 사이드바만 열어도 모자라고, 리딩 분할에선 거의 언제나 모자란다.
- 덤으로 iframe **요소** 폭(`clientWidth`)으로 재서 안쪽 스크롤바 폭만큼 낙관적이었다.

## 변경

- `lib/annot/railFit.ts`(순수) — 그대로 들어가면 비키기만, 안 들어가면 **카드를 좁혀서라도** 레일 자리를 만든다.
  단 카드가 480px 밑으로 내려가야 하면 펼치지 않는다(툴팁으로). 폭은 iframe 문서의 `documentElement.clientWidth`(스크롤바 제외) − body 여백.
- `lib/annot/mode.ts` + 설정 [표시 펜] **켜기 · 보기만 · 끄기**(기본 켜기 · 영속):
  - 보기만 = 단 표시·메모·알약·레일은 그대로, 눌러 고치고 지우기도 됨 — **새로 다는 길**(드래그 트레이 · 여백 ＋)만 닫는다. 신고 1 의 답은 이것이다.
  - 끄기 = 표시·알약·레일·툴팁 전부 숨김. **저장된 표시는 안 지운다**(다시 켜면 그대로). 이미 그린 SVG 층은 빈 목록으로 다시 그려 지운다(iframe 은 다시 안 불러온다).
  - 모드를 바꾸면 떠 있던 트레이·＋·툴팁을 걷는다.
  - 순수 "끔/켬" 대신 셋인 이유: 거슬리는 것은 드래그 트레이뿐인데 끔 하나로 답하면 이미 단 표시까지 안 보이게 된다.
- `AnnotLayer.tsx` · `SettingsPopover.tsx` · 스토어 `annotMode` · ko/en 문구(버튼 `title` 에 모드 설명).
