# 2026-10-12 (05) [v1.1] 진행 계획 — 후속 기능 먼저, Store 는 1.1.0 으로 한 번에

브랜치 `develop-roadmap-11` · 사용자 결정 2026-10-12

## 배경

1.0.0 GitHub 출하 직후, 남은 계획(촬영 → Store 1.0 → 1.1)을 두고 사용자가 순서를 바꿨다: "1.0.0 은 릴리즈 파일만
준비해 두고, 변경 다 포함한 상태로 후속 기능 추가부터. 최종 기능 완료해서 스토어 제출 후 지금 브리지 테스트하는 것
변경에 대한 마이너 버전업." 1.1 순서는 "표시 펜 먼저, 브리지 소품 곁들여"(권장안). 이어서 "이미 목업으로 확인했으니
자율적으로 진행하고 기능 확인할 것".

- **Store 는 0.10.0 → 1.1.0 으로 건너뛴다** — 1.0 의 고친 것은 1.1 What's new 에 함께 적는다(Store 사용자에게는 처음).

  판올림이다. 그래도 실사용 DB 사본 리허설을 V2 완료 조건에 둔다.
- **유료화는 V3 끝에 판단** — 게이팅 코드는 미리 넣지 않는다.
