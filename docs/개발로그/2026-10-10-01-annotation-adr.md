# 2026-10-10 (01) [설계] 표시 펜 — 형광펜·색연필·메모 ADR 0003 + 동작 시안

브랜치 `develop-annotation-adr` · WBS #916

## 배경

사용자 제안: 리딩 화면에 형광펜·그리기 캔버스를 덮어 문서의 강조 영역을 표시하고 메모도 하자. 같은 계정
ShotLog 에 드로잉 도구가 있으니 참고해 적절성을 봐 달라. 대화로 방향을 다듬으며(캔버스 → 글자 앵커 →
스냅샷 고정 → 펜 세트·뜻 → 질감 → 메모 접힘) 구현 전에 결정을 닫았다.

  여백 ＋ → 점 표시 · 칠한 곳 클릭 → 고치기/지우기 · 테마 셋 · 폭 셋(리플로우해도 표시가 따라간다) · 질감

## 결정·함정

- **ShotLog 방식은 이 앱에서 성립하지 않는다** — `AnnotationWindow` 는 고정 비트맵 위 `InkCanvas` 를 [완료]
  때 픽셀로 굽는다. 미리보기는 리플로우되고 에이전트가 문서를 고쳐 쓰므로 좌표 기반 표시는 *조용히*
  어긋난다. 가져온 것은 도구 구성(색·굵기·되돌리기)이라는 UX 어휘뿐.
- **질감을 원한 순간 CSS Highlight API 가 탈락했다** — 단색 배경만 칠한다. 모든 표시를 SVG 층에서 그리고,
  질감 끄기는 같은 경로에서 필터만 빼는 것으로(경로가 둘이면 모양이 갈린다).
- **수평선에 SVG 필터를 걸면 사라진다** — bbox 높이가 0이라 기본 필터 영역(objectBoundingBox)이 0이 된다.
  `filterUnits="userSpaceOnUse"` 로 층 전체를 영역으로 잡았다. 덤으로 종이 결이 문서 좌표에 고정된다.
- **시안 상단 막대도 앱 툴바와 같은 병을 앓았다** — 좁아지면 라벨이 세로로 접혔다. `.bar > * { flex: none }`
  + 힌트만 줄어들게. "줄어들게 둔 것"이 원인이라는 v0.10 의 교훈 그대로.
- 기록 쪽에서 가장 중요한 한 줄: **표시가 참조하는 스냅샷은 정리에서 뺀다** — 안 하면 바쁜 문서에서 바탕
  판이 조용히 지워진다.

## 검증

- 헤드리스 Edge 캡처(1440·1280·900px, 배율 2.5 확대) — 형광펜 가장자리·가로 결, 색연필 알갱이 실제로 보임 ·
  시연 표시 9개 + 사라짐 1개 렌더 · 툴팁 카드(`#tip`)가 다른 표시를 흐리며 뜸 · 상단 막대 넘침 없음.
- `--dump-dom` 으로 스크립트 무오류 확인(요약 알약 `메모 3 · 바뀜 1 · 위치 잃음 1`).
- 코드 변경 없음(문서·시안만) — tsc·vitest·프로브 대상 아님.

## 비목표

- 구현 — 1.0 위생 뒤 1.1 후보. 유료화(Pro) 범위 여부는 열어 둠.
- 캔버스 파일(옵시디언 Canvas 류) — 다음 검토 항목으로 로드맵에만 올렸다.
