## 결정·함정

- **GitHub 와 Store 가 한동안 다른 판이다**(1.0.0 / 0.10.0). README 의 Store 링크로 들어온 사람은 0.10.0 을 받는다 —
  1.0 에서 고친 브리지 다섯도 그때까지 Store 판에는 없다. 그래서 P1 실사용의 브리지는 여전히 0.10.0 이고, P6 에서
  Store 서명본으로 7/7 을 다시 돌린다.
- **10-18 뒤 화면이 바뀌는 수정이 나오면 1.0.1** — 촬영은 Store 에 올릴 그 커밋으로 해야 하므로, 1.0.0 MSIX 를 그대로
  제출할지는 P2 에서 정한다.
- 셸 함정 하나: 명령 맨 앞의 `cat > 파일`(헤어독 없이)은 stdin 을 기다리며 2분 동안 멈춘다 — 스크립트는 Write 로 썼다.
