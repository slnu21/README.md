## 결정·함정

- **사용자 지적 셋을 반영**: ① 연결 위치를 못 고른다 → 가장 가까운 연결점 스냅 + 선 끝 손잡이 ② 선이 그룹
  상자 밑이라 그룹 안 선을 못 누른다 → 층 분리(그룹 → 선 → 카드) ③ 카드 미리보기는 아웃라인까지, mermaid
  같은 렌더는 하지 않는다 → 본문 단계 삭제.
- **선 옮기기가 새 선을 만들던 결함** — 손잡이가 카드 층 밑이라 같은 자리의 카드 연결점이 잡혔다. 그리고
  변 없는 선은 한쪽을 옮기면 자동 계산이 *반대쪽 출발 변까지* 바꿨다. 손잡이를 맨 위 층으로, 옮길 때 반대쪽
  변을 고정 저장. **`elementFromPoint` 히트 테스트로 고치기 전(`span.h` · 선 5→6)과 후(`circle.knob` · 5→5)를
  둘 다 봤다** — 캡처로는 안 보이는 결함이다.
- **텅 빈 캔버스 — 크롬 렌더 함정**: `transform:scale` 된 world 안의 overflow 가진 flex 항목 → 노드 묶음 전체가
  안 그려짐. 잉크·라벨·블렌드·will-change·isolation 등 변형 열 개 남짓으로 지워 가며 좁혔다. GPU 켜도 같다.
- **카드 안 글자 위 드로잉은 어긋난다** — 시연용 형광펜을 글 상자 한 줄에 그었더니 확대 단계가 바뀌자 떠
  있었다. 캔버스 펜(카드 사이·주변)과 표시 펜(카드 안 글자)의 경계가 여기서 나왔다.

## 검증

- 헤드리스 Edge 캡처 — 제목 단계 · 아웃라인 단계 · JSON 패널(가로 넘침 없음) · 그룹 안 선 선택(손잡이·선택
  막대) · 연결 중 스냅(강조된 연결점 + 점선).
- `#relink` 자가 점검을 `--dump-dom` 제목으로 확인 — 수정본 PASS, 손잡이 층만 되돌린 변형은 FAIL(선 5→6).
- 코드 변경 없음(문서·시안만).
