# 2026-11-13 (03) 메모 툴팁이 잘 안 뜨던 것 — 움직일 때마다 머무름 타이머를 다시 걸었다 · v1.1.1 에 수록

브랜치 `develop-annot-hover` · [features/annotations.md](../design/features/annotations.md) · 실사용 피드백 "메모 달린 곳에 마우스 올려도 보기가 힘들다"

## 원인

판정 영역이 좁거나 글자가 간섭하는 문제가 아니었다. `mousemove` 마다 `clearTimeout` 후 450ms 타이머를 **처음부터 다시** 걸어서,
마우스가 1px 이라도 움직이면 기다림이 리셋됐다 — 사람 손은 멈춰 있지 않으니 사실상 안 뜬다. `probe:annot` 의 [툴팁]은 mousemove 를
**한 번만** 보내 이 경우를 못 쟀다.

## 변경

- `lib/annot/hoverIntent.ts`(순수) — `{pending, shown}` 상태로 **다른 표시로 넘어갈 때만** 타이머를 건다. 같은 표시 위 움직임은 아무것도 안 바꾼다.
  뜬 툴팁의 표시 위면 닫기 예약 취소 · 밖으로 나가면 걸린 타이머는 풀고 뜬 툴팁은 닫기 예약 · 툴팁이 뜬 채 다른 표시로 가면 닫지 않고 새로 건다.
- 닫기 유예 250 → **400ms**(표시 → 틈 → 툴팁으로 손을 뻗는 시간) · 툴팁이 다른 데서 닫히면(Esc·스크롤·트레이) `shown` 을 맞춘다.
- 범위 표시 판정 여유 x ±3 → ±4, y −2/+4 → **−4/+6** — `getClientRects` 줄 상자는 글자 상자라 줄 사이 틈이 비고, 밑줄·물결은 글자 아래에 그려진다.
- **v1.1.1 에 수록** — 아직 안 나간 판이라 버전은 그대로. CHANGELOG · 릴노트(ko/en) · store-listing What's new 에 한 줄씩 · 산출물 재빌드·재패킹.
