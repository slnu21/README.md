# 2026-10-12 (12) [v1.1 C1] 캔버스 형식 — JSON Canvas 1.0 읽기·쓰기 · 기하 · file 노드 경로

브랜치 `develop-canvas-format` · [ADR 0004](../design/decisions/0004-canvas-document-map.md) 단계 ① 의 순수 로직

## 배경

사용자 결정(같은 날): **표시 펜은 무료**, **다음 작업(캔버스)도 자율로, 그 버전 기준으로 스토어 배포 준비까지**. 1.1.0 도 1.2.0 도
아무 데도 안 나갔으므로 **1.1.0 = 표시 펜 + 캔버스**로 묶는다([roadmap-1.1.md](../design/roadmap-1.1.md) 2.5절).

## 변경 — `src/app/lib/canvas/`

- `format.ts` — `parseCanvas`·`serializeCanvas`(탭 들여쓰기 — 옵시디언과 같은 모양). **파싱한 객체를 그대로 들고 고친다** → 노드·선·최상위의
  모르는 필드가 저절로 보존된다. 형식이 틀린 노드·매달린 선도 지우지 않고 그리지만 않는다(`drawable`). JSON 이 아니면 던진다(빈 캔버스로
  조용히 덮으면 저장 때 원본이 날아간다). 색은 프리셋 1~6(`--canvas-c*`) 또는 hex 만. 노드를 지우면 붙은 선도. 그룹은 화면에서만 아래로.
- `geometry.ts` — 연결점 · 자동 변 · 베지어(화살표·라벨 중점) · 가장 가까운 변 · 달라붙기(그룹보다 카드) · **`relink` 가 반대쪽 변을
  고정 저장**(ADR 4절 — 출발지가 제멋대로 바뀌던 것) · 그룹 구성원 · 확대(커서 고정)·전부 보기.
- `paths.ts` — 옵시디언은 **볼트 루트 기준 상대 경로**. 읽기 후보: 볼트 루트(`.obsidian` 조상, Rust 가 찾는다) → 캔버스 폴더 → 조상.
  쓰기: 볼트 안이면 볼트 기준, 밖이면 캔버스 폴더 기준(`../` 허용) · 드라이브가 다르면 절대.
