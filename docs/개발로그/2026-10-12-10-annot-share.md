  도구 7개 — 금지 이름(쓰기) 테스트 유지.

- **[리뷰 요약 복사]** — 요약 알약 옆 · 내보내기 메뉴 · 팔레트. `summary.ts`(칠한 문장 + 뜻 + 상태 + 줄 + 메모 → 마크다운).
- `lib/annot/paint.ts` — 그리기 핵심을 AnnotLayer 에서 떼어 냄(`ANNOT_DOC_CSS` 포함).
- 문서: agent-bridge.md 계약 표 · README 연결 절 ko/en 에 `list_annotations` · **개인정보 처리방침 2절(표시·메모 = 로컬 저장, 바탕 사본) ·

## 결정

- **PDF 는 SVG 굽기 대신 CSS 표시** — ADR 은 "화면과 같은 질감을 굽는다"였지만, 인쇄 문서는 숨김 iframe(0×0)이고 쪽 폭은 인쇄 대화상자에서
  정해진다(A4·Letter). 미리 잰 좌표가 인쇄 배치와 맞는다는 보장이 없다 — 질감보다 자리가 먼저다. 한 번 그렇게 만들었다가 이 이유로 되돌렸다.

## 함정

- **git `autocrlf` 가 픽스처를 CRLF 로 바꿔 둔다** — 프로브·테스트의 `replace("…\n", …)` 가 조용히 안 먹어 "에이전트식 수정"이 한 낱말
  바꾸기로 줄었고, 실제 픽스처로 박은 relocate 테스트가 **공허하게 통과**하고 있었다. 읽을 때 LF 로 맞추고, 고친 줄 짝짓기·빈 줄 합치기를 둘 다
  끄면 테스트 셋이 FAIL 하는 것을 다시 봤다(앱은 `readFile` 이 이미 LF 로 맞춘다).
- 헤드리스 하네스가 던지면 그때까지의 실패가 버려졌다 — catch 가 실패 목록을 함께 보낸다.
- 실구동 스크립트의 기대값(줄 7)이 낡아 있었다 — 위에 두 줄을 끼웠으니 9 가 맞다. 숫자가 이상하면 판정보다 기대값을 먼저 의심.
