# 1.0 촬영 계획 — 스토어 스크린샷 8장 + 영상 브리지 비트 (U4 · U5)

> **촬영은 2026-10-18(브리지 실사용 1주) 이후.** 실사용에서 화면이 바뀌는 수정이 나오면 그걸 먼저 넣고 찍는다.
> 이 문서는 2026-10-12 에 쓴 계획이다. 촬영 절차의 바탕은 [copy.md](copy.md) §5(좌표·입력 주입·함정)이고, 여기는
> **1.0 에서 달라지는 것만** 적는다.

## 0. 1.0 촬영에서 달라지는 것 — 실사용 데이터를 옮기지 않는다

0.6.8 촬영은 `userdata.ps1` 로 실사용 DB·WebView2 프로필을 비켜 놓고 찍었다. **지금은 그게 거부될 때가 많다** —
Store 설치본 브리지(`readme-md mcp`)가 에이전트 세션 내내 실사용 DB 를 잡고 있기 때문이다(10-11 에 겪음). 그래서
U6 실측·성능 재측정과 같은 방법으로 찍는다:

- **촬영용 exe 를 임시 식별자 `com.readme.shoot` 로 빌드**(`tauri.conf.json` `identifier` + `app_paths.rs` `APP_IDENTIFIER` 두 줄,
  detached worktree 에서, 커밋 안 함 — [packaging/update-check/README.md](../../packaging/update-check/README.md) 와 같은 법).
  데이터가 `%APPDATA%\com.readme.shoot` 로만 간다. 화면은 실물과 같다 — 식별자는 화면에 안 나온다.
- **에이전트 연결 패널도 실물과 같다** — 패널은 `%LOCALAPPDATA%\Microsoft\WindowsApps\readme-md.exe` 가 있는지만 본다
  (`commands/agent.rs`). 이 기계에는 Store 설치본이 있으므로 촬영용 exe 도 `readme-md mcp` 를 안내한다.
- "마지막 연결" 시각을 채우려면 **촬영용 exe 의 MCP 모드**를 한 번 붙인다(`md-reader.exe mcp` 에 `initialize` 한 줄 —
  같은 식별자라 촬영용 DB 에 기록된다). Store 브리지로는 안 된다(실사용 DB 에 쓴다).
- `stage.ps1` 의 실사용 데이터 가드(`com.readme.app.shootbak` 확인)는 식별자가 다르면 필요 없다 — 촬영 전에
  `-Identifier` 를 받게 고친다(아래 §3 준비물).

판: **1.0.0 으로 올린 커밋**(버전 상향 = 확인 게이트 뒤). 화면 어디에도 버전이 안 나오지만, 찍은 뒤에 화면을 바꾸는
수정이 들어가면 다시 찍어야 하므로 촬영은 출하 직전 커밋으로 한다.

## 3. 데모 워크스페이스 준비 — `D:\Workspace` 재사용

0.6.8 때 만든 데모(`make-demo.ps1` · 저장소 6개 · md 62개)가 그대로 있다(10-12 확인). 1.0 에 더할 것:

1. **RTL 문서** — `docs/samples/rtl-persian.md` 를 `D:\Workspace\Notes\` 로 복사(8번).
2. **"밤사이 에이전트" 스크립트** `video/capture/overnight.ps1`(로컬 · gitignore) — **폴더를 가져오고 앱을 닫은 뒤** 돌린다.
   보고서 2편 새로 쓰기(한국어 1 · 영어 1) + 기존 문서 4편 고치기(절 하나 추가 · 숫자 갱신). 앱을 다시 켜면 부팅 재색인이
   잡아 종에 6이 뜨고, 고친 4편은 색인이 덮기 직전 판이 기록에 남는다(1·2번 · B3b). 한글은 스크립트가 아니라 데이터
   파일(`overnight-*.txt`)에 둔다(PS 5.1 ANSI 함정).
3. **두 번 찍을 수 있게** — 스크립트는 고칠 문서를 고치기 전에 `.orig` 로 떠 두고 `-Reset` 으로 되돌린다(촬영용 DB 는
   `com.readme.shoot` 폴더를 지우면 처음으로 돌아간다).
4. `stage.ps1` 에 `-Identifier com.readme.shoot`(실사용 가드 대신 식별자 확인 · 촬영용 exe 경로).

## 4. 촬영 순서(10-18 이후, 한 세션)

1. 1.0.0 커밋으로 촬영용 exe 빌드(`com.readme.shoot`) → `stage.ps1 -Fresh -Identifier com.readme.shoot`.
2. 설정(copy.md §5-4) · `workspace.json` 주입 · 앱 닫기 → `overnight.ps1` → 앱 켜기.
3. 촬영용 MCP 한 번 붙이기(패널의 "마지막 연결").
4. ko 8장 → 언어 EN → en 8장 → 영상 컷 B3b 4장(+ 기존 컷 중 화면이 바뀐 것: 툴바가 바뀐 `06-split`·`11-palette` 재촬영 검토).
5. `overnight.ps1 -Reset` · `com.readme.shoot` 폴더 삭제.

## 5. 찍기 전에 확인할 것

- 리스팅 문구가 말하는 기능이 화면에 다 있는가(받은 문서함 · 문서 기록 · 에이전트 연결 · 글 방향 · 테마 창).
- 스크린샷에 **사용자 프로필 경로·실사용 문서가 안 나오는가** — 데모 워크스페이스만, 툴팁 `Park`.
- 1·2번의 숫자(종 배지 · 판 개수)가 스크립트 결과와 맞는가 — 스크립트가 만든 수를 출력하게 한다.
